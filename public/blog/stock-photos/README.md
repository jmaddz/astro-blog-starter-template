# stock-photos

Licensed stock photography for the blog and site pages. Reference from a post's
frontmatter as:

    heroImage: "/blog/stock-photos/<filename>"

or inside post text as ![alt text](/blog/stock-photos/<filename>).

Conventions:

- lowercase filenames, dashes instead of spaces (sore-neck.jpg, not Sore Neck.jpg)
- keep files a few hundred KB where possible (export at ~1020px wide for hero use)
- files named iStock-*.jpg are iStock licensed under the account licence; this
  folder is the licence record, keep filenames aligned with the iStock asset IDs.
